# Nike Landing Page

A modern, responsive Nike-inspired landing page built with React, Vite, and Tailwind CSS.

## Tech Stack

- **React 19** - UI library
- **Vite 6** - Build tool and dev server
- **Tailwind CSS 3** - Utility-first styling

## Features

- Responsive design for all screen sizes
- Modern UI with smooth transitions and hover effects
- Reusable component architecture
- Fast development with Vite HMR
- Optimized production builds

## Prerequisites

- Node.js 18+ 
- npm or yarn

## Installation

```bash
# Clone the repository
git clone https://github.com/sam-holtz/nike-landing-page-react.git

# Navigate to project directory
cd nike-landing-page-react

# Install dependencies
npm install
```

## Development

```bash
npm run dev
```

Starts the development server. Open [http://localhost:5173](http://localhost:5173) in your browser.

## Build

```bash
npm run build
```

Creates an optimized production build in the `dist` directory.

## Preview

```bash
npm run preview
```

Serves the production build locally for testing.

## Project Structure

```
src/
├── assets/       # Images and icons
├── components/   # Reusable UI components
├── constants/    # Data and configuration
├── sections/     # Page sections
├── App.jsx       # Main app component
├── index.css     # Global styles
└── main.jsx      # Entry point
```
